# Garden Match Road Demo

竖屏轻量 HTML 试玩原型。核心流程：交换两色棋子完成三消 → 消除棋子逐枚飞向外围灰格铺路 → 本轮铺路结束后人物连续跳格 → 经过钱堆触发撒钱反馈。

入口文件为 `index.html`，视觉素材位于 `assets/`。直接打开入口文件即可试玩；如浏览器限制本地资源，可在本目录启动任意静态文件服务。

当前版本使用与参考图一致的蓝黄交错固定初始棋盘和受控补充序列：外围20个阴影格构成铺路区域，中间4×4棋盘直接放置在连续泥地上，没有底部阴影格。中间16枚棋子的中心位置按1145×2048参考图逐点测量，棋子可见本体尺寸也按参考图比例校正。外围20个阴影则按当前940×1672背景逐格测量中心与边界，铺路棋子会针对每格透视大小贴合阴影。棋盘内仍保持蓝黄亮面棋子；飞出及铺路状态使用灰褐色哑光粗石板 PNG，表面包含明显凹坑、孔隙、砂砾纹理和不规则缺边。棋盘连消计算与外围铺路队列并行执行，下一批匹配会在补充后立刻继续消除，不等待人物完成当前跳跃；铺路本身仍按顺序连续播放。每次消除仅第一枚石板从棋盘飞到新路段起点，其余石板从该起点沿路线快速逐格铺开；人物边铺边快速跳，并按照屏幕纵向移动方向在正面和背面素材间自动切换，普通格不回弹，只有第20格铺满后的最终落地回弹并触发完成。钱堆保持持续上下漂浮、轻微摆动、独立动态投影和收集腾空效果。问号终点暂未加入玩法。没有外部代码、字体或 CDN 依赖。未配置产品商店地址，因此暂不加入 CTA。未提供匹配画质的音频素材，因此没有加入音效或 BGM。

场景、人物、棋子和钱堆均使用参考图派生或生成的高清位图资产；人物在待机时使用原正面图，向画面上方铺路时切换为同角色、同服装、双腿平行且双脚靠拢踩地的背面透明 PNG，并按路径方向左右翻转。代码仅负责运动、布局与纸币粒子反馈，没有用低保真 Canvas/SVG 重画核心画面。现金奖励直接使用用户提供的透明“+100”PNG。道路全部铺满后不再显示遮罩弹窗，改为全画面持续洒落彩条；终点庆祝由正面站立帧与正面腾空举手帧组成两帧循环，跳跃帧保持双腿和双脚并拢直线上跳，庆祝阶段不再出现背面人物。顶部重置按钮仍可重新开始。参考素材中的第三方界面文字和品牌标识没有进入本 Demo。

操作引导仅在每次开局时出现一次，文案为英文“SWAP TO MATCH 3”：两枚推荐交换的棋子保持原本蓝黄颜色，仅轻微上下浮动，不再显示手势或箭头。玩家完成第一次交换后，本局不再重复显示引导，重新开始新一局时才会再次出现。第一次消除后的补充仍为蓝黄两色，从第二次消除后的补充开始提高同尺寸正红色方形棋子的比例，降低连续自动消除概率。每次玩家有效交换后，棋盘上方会用石板图标配“×数量”显示该次操作实际消除的总棋子数；提示没有底色、边框或胶囊外框。同一次操作的连击会继续累加，下一次操作重新从零统计。连击反馈去掉外框并统一在一行居中显示为英文“COMBO x数字”。顶部铺路进度条已移除，左上角改为钱堆图标与金币总数框，初始为0，每次收集钱堆增加100。金币数字、COMBO 和数量提示使用本地打包的 MuseoModerno 可变字体；金币框按参考图校准为画面宽度约28%、左边距约6.3%、高度约5.8%，纸币图片缩小并保留透明留白。消除发生后，棋盘掉落补充会立刻开始并与外围铺路同步进行。人物会依据下一个落点自动左右转身。

无效交换只恢复棋子位置，不再出现“再试一次”文字提示。

已知限制：人物采用单张透明 PNG 配合程序化起跳、腾空与落地形变，尚不是骨骼动画或完整序列帧；首版优先验证玩法与反馈节奏。当前未输出 AppLovin 投放包。
